StyleVerse prototype - how to run
=================================

WINDOWS: double-click start-styleverse.cmd
MAC:     double-click start-styleverse.command
         (first time: right-click > Open, if macOS blocks it)

Your browser opens http://127.0.0.1:4173/ automatically.
Keep the terminal window open while you use it; close it to stop.

If Node.js is missing, the script opens nodejs.org - install the LTS
version and run the start file again.

No API key is needed. The AI panels and the "Ask StyleVerse" assistant
use pre-built demonstration responses based on the prototype's
synthetic data.

Shortcut: you can also just double-click public/styleverse-studio-layout.html
to open it directly in a browser without the server.
